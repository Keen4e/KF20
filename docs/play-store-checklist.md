# Play Store release checklist

- [ ] Confirm final product name, icon, application ID and support email.
- [ ] Create/confirm Google Play Console developer account.
- [ ] Create a production signing key and store it securely outside the repository.
- [ ] Complete Data safety, content rating, target audience and privacy policy URL.
- [ ] Provide store listing: short/long description, screenshots, feature graphic and contact details.
- [ ] Test release build on at least one physical Android device.
- [ ] Upload signed Android App Bundle (`.aab`) to internal testing.
- [ ] Resolve Play pre-launch report issues, then promote to production.
